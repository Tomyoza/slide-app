# SlideApp: Modernizing Traditional Strategy

An Android application developed to bridge cultural gaps by introducing **Gomoku** (Japanese Five-in-a-Row) to an international audience through an intuitive, pixel-art interface.

### 🌟 Project Vision
While studying at **Brigham Young University–Hawaii**, I noticed a lack of accessible tools to share Japanese board game culture with my international peers. I developed **SlideApp** to lower the barrier to entry, combining traditional strategy with casual mobile gaming aesthetics.

### 🌎 Multilingual Support
To ensure the game is accessible to both local and international users, the app features full localization in:
* **English**: For international students and global users.
* **Japanese**: For native speakers and those interested in the original cultural context.

### 🛠 Technical Specifications
* **Development Environment**: Android Studio.
* **Language**: Java.
* **Platform**: Android SDK (Native).
* **Key Implementation**:
    * **Custom Grid Logic**: Engineered a turn-based system using Java to handle 2D array manipulations for the game board.
    * **Win-Condition Algorithm**: Implemented an efficient search algorithm to detect five consecutive pieces in all directions (horizontal, vertical, and diagonal).
    * **Localization Framework**: Utilized Android’s `string.xml` resource management to implement a scalable multilingual architecture.

### 🎨 Design & UX
* **Pixel Art Aesthetic**: Custom-designed sprites and a "Slime" mascot to create a friendly, approachable atmosphere for new players.
* **Visual Feedback**: Real-time UI updates and visual cues for player turns to ensure a smooth user experience.
* **Localized Context**: Designed specifically as a cultural education tool for a diverse user base at an international university.

### 📂 How to Explore
The core game logic, including the board state management and win-condition checks, is located within the `app/src/main/java/` directory. This project reflects my ability to build functional, user-centric mobile applications using industry-standard native development tools.
